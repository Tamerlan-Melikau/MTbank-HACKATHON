# Семейный кошелёк

Прототип детско-семейного банкинга в Moby для хакатона МТБанка: карта ребёнку 7–13 или 14–17 лет, родительский контроль, личный доступ ребёнка в приложение с согласия родителя, запросы «можно?», задания, уроки и баллы.

Устройство кода описано в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Vite покажет адрес в локальной сети (`Network: http://192.168.x.x:5173`): его можно открыть с телефона в той же Wi-Fi-сети.

## Проверки

```bash
npm run check
```

Проверяет типы и запускает тесты доменных правил и сценариев «сервера».

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions** (один раз).
2. Push в `main` запускает `.github/workflows/deploy.yml`: тесты, сборка, публикация.
3. Адрес: `https://<владелец>.github.io/<репозиторий>/`.

Ссылки вида `…/#/child/m_misha` работают напрямую. На телефоне: «Поделиться → На экран Домой», и приложение откроется без панели браузера.

## Демо

На стартовом экране выберите персонажа: родителя (Анна, Сергей) или ребёнка (Миша 10 лет, Катя 15 лет). Данные хранятся только в этом браузере, «Сбросить демо» возвращает исходное состояние.

Сценарий для показа: откройте две вкладки и войдите в одной родителем, в другой ребёнком.

1. Ребёнок (Миша): «Оплатить» → «Книжный», 21 BYN → «Ждём родителя».
2. Родитель: «Запросы» → «Разрешить», деньги списываются у ребёнка.
3. Ребёнок: «GameStore» → отказ «Родитель запретил эту категорию» → «Попросить разрешение».
4. Ребёнок: «Букмекер» → отказ без возможности запросить: категория запрещена всегда.
5. Родитель: «Добавить ребёнка» → пакет → «Выдать код»; на стартовом экране «Войти по коду» → родитель подтверждает доступ.
