# Семейный кошелёк

Прототип детско-семейного банкинга в Moby для хакатона МТБанка: карта ребёнку 7–13 или 14–17 лет, родительский контроль, личный доступ ребёнка в приложение с согласия родителя, запросы «можно?», задания, уроки и Манички.

Устройство кода описано в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Vite покажет адрес в локальной сети (`Network: http://192.168.x.x:5173`): его можно открыть с телефона в той же Wi-Fi-сети.

## Проверки

```bash
npm run check
```

Проверяет типы и запускает тесты доменных правил и сценариев «сервера».

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions** (один раз).
2. Push в `main` запускает `.github/workflows/deploy.yml`: тесты, сборка, публикация.
3. Адрес: `https://<владелец>.github.io/<репозиторий>/`.

Ссылки вида `…/#/child/m_misha` работают напрямую. На телефоне: «Поделиться → На экран Домой», и приложение откроется без панели браузера.

## Демо

На стартовом экране выберите персонажа: родителя (Анна, Сергей) или ребёнка (Миша 10 лет, Катя 15 лет). Данные хранятся только в этом браузере, «Сбросить демо» возвращает исходное состояние.

Сценарий для показа: откройте две вкладки и войдите в одной родителем, в другой ребёнком.

1. Ребёнок (Миша, 10 лет): «Перевести» → указать любого получателя и 10 BYN → «Ждём родителя». Любой перевод ребёнка до 14 лет выполняется только после одобрения родителя.
2. Родитель: «Запросы» → «Разрешить», 10 BYN списываются у Миши и зачисляются выбранному им получателю (например, Кате, если Миша указал её).
3. Ребёнок (Катя, 15 лет): «Перевести» → 20 BYN → перевод проходит сразу.
4. Ребёнок (Миша): «Копилка» → создать цель → «Отложить»; деньги закрепляются внутри счёта «МТБелки», свободный остаток уменьшается. Если счёта нет, приложение предложит его открыть. Родитель в профиле Миши → «Копилки» → «Управлять» может создавать цели, откладывать, забирать и закрывать их.
5. Родитель: выбрать Катю → «Открыть счёт «МТБелки»» → открыть счёт, посмотреть остаток и операции или закрыть его (до 14 лет счёт открывает только родитель). Минимум первого пополнения — 10 BYN; ставка 10% годовых — допущение прототипа. Катя 14+ может запросить открытие сама, родитель подтверждает.
6. Ребёнок: «МТБелки» → «Пополнить с основного счёта». Катя 14+ пополняет сразу. Миша до 14 отправляет запрос, родитель подтверждает его в «Запросах», и деньги переходят с основного счёта ребёнка на «МТБелки».
7. Родитель: профиль Миши → счёт «МТБелки» → «Проценты банка»: задать долю процентов в копилки и нажать «Начислить проценты (демо)». Проценты считаются от всего остатка, включая суммы в копилках; Миша это правило не видит.
8. Там же «Проценты от родителя»: задать свою ставку и нажать «Начислить проценты от родителя (демо)». Дополнительный процент считается от всего остатка и списывается с основного счёта родителя.
9. Родитель: «Добавить ребёнка» → после выпуска карты сразу видит одноразовый код. Ребёнок на стартовом экране вводит его в разделе «Подключиться к родителю по коду»; после первого ввода код исчезает, а родитель подтверждает доступ в профиле ребёнка. Только после подтверждения вход в Moby открывается.
10. Родитель: «Продукты» → карточка ребёнка → «Страхование ребёнка» → «Оформить» / «Отключить». Управлять страховкой может только родитель; ребёнок её не оформляет.
11. Ребёнок: «Уроки» → пройти урок → получить Манички. Манички — баллы от банка за уроки; задания родителей тоже могут их приносить. Это не деньги.
