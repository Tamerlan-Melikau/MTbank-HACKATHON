Горизонтальный баннер с заголовком, короткой строкой и действием.

Потребитель передаёт: заголовок (до 3 слов), строку описания (до 60 символов), подпись действия.

- Заливка `accent` с текстом `on-accent` или заливка `brand` с `on-brand`; `radius-md`, отступ `space-4`, между баннерами `space-3`.
- Заголовок — `heading`, описание — `body`. Не клади на баннер изображения с текстом и градиенты.
- Действие — текстовая ссылка с шевроном, цель касания не меньше 44px.
- Не больше двух баннеров на экране.
