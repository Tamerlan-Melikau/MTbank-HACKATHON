Шапка главного экрана: имя владельца, маска счёта, баланс и четыре быстрых действия на заливке `brand`.

Потребитель передаёт: имя, название и маску счёта, сумму (уже отформатированную, с кодом валюты), четыре действия (иконка + подпись), число непрочитанных уведомлений.

- Заливка `brand`, нижние углы `radius-lg`, отступы `space-6` по бокам и `space-5` снизу; текст `on-brand`.
- Сумма — `display`. Кнопка «скрыть сумму» заменяет цифры на «••••», подпись валюты остаётся.
- Ровно четыре действия, подпись `label`. Лишние действия уходят на отдельный экран.
- Не показывай сумму в уведомлениях и на экране блокировки.
