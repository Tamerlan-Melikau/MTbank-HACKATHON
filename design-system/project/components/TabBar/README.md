Нижняя навигация из четырёх вкладок: Главная, Продукты, Чат, Ещё.

Потребитель передаёт: активную вкладку и число уведомлений для «Ещё».

- Панель на `surface-200`, верхние углы `radius-lg`, иконка 24px над подписью `label`.
- Активная вкладка — `brand` (иконка и подпись) на фоне `brand-soft`; неактивные — `ink-muted`.
- Счётчик — круг `radius-pill` на `accent` с текстом `on-accent`; число больше 99 пиши «99+».
- Вкладок всегда четыре, порядок не меняется.
