Ряд из четырёх быстрых действий: квадратная кнопка с иконкой и подпись под ней.

Потребитель передаёт: четыре пары «иконка — подпись»; подпись — один глагол.

- Кнопка на `surface-200` (в шапке) или `surface-300` (на экране), `radius-md`, высота 56px, подпись `label` в `ink`.
- Расстояние между кнопками — `space-2`, иконка 26px, штрих 1.75px.
- Не больше четырёх; пятое действие — в «Ещё».
- Нажатие даёт отклик сменой фона на `brand-soft`; цель касания не меньше 44px.
